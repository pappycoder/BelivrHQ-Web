Guards against refresh loops (single retry, `allowRefresh=false` recursion).
  - **`src/hooks/use-auth.tsx`** — `AuthProvider` now:
    - Registers the global unauthorized handler on mount (clear tokens → redirect `/login` → "Your session has expired. Please sign in again." toast).

    - `finalizeLogin` persists `refreshToken` and schedules the refresh; extracted shared teardown (`handleSessionEnd`: clear cookies + state + query cache + redirect) reused by both explicit `logout` and the forced-expiry path, latched (`loggingOutRef`) to prevent duplicate toasts/redirects from stale in-flight 401s after a session ends.
